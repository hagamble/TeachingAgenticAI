# Vorbereitung für den Kurs "Agentic AI mit Claude Code"

Bitte bis **[Datum eintragen]** erledigen. Das dauert ca. 20–30 Minuten.
Wenn etwas nicht klappt: **[Kontakt oder Sprechstunde eintragen]**.

## 1. Einen eigenen Gmail-Account für deinen Agenten anlegen
- Neue Adresse nach dem Muster `NameXAgt@gmail.com`, z.B. `maxmusterxagt@gmail.com`. Wenn der Name vergeben ist: `vorname.nachnamexagt`.
- Bitte **nicht** deine private oder deine Firmen-Adresse verwenden.
- Google verlangt dabei eine Telefonnummer, das ist normal.

## 2. Einen GitHub-Account anlegen
- Unter https://github.com/signup, falls du noch keinen hast. Der kostenlose Plan genügt.
- Notiere dir deinen Username.

## 3. Bei Claude anmelden
- Unter https://claude.ai mit deinem **HSG-Account** anmelden.
- Claude Code im Web öffnen: https://claude.ai/code
- GitHub verbinden, wenn du danach gefragt wirst.

## 4. Den Gmail-Connector verbinden
- In Claude unter Einstellungen → Connectors → Gmail verbinden.
- Dabei den **`…XAgt`-Account** auswählen, nicht deine private Adresse.

## 5. Dein Kurs-Repo erstellen
- Diesen Link anklicken: **[GitHub-Classroom-Link eintragen]**
- Damit entsteht automatisch dein eigenes, **privates** Repo.

## 6. Testen
- [ ] In Claude Code eine Session mit deinem Kurs-Repo starten und eingeben: `Erkläre mir in 3 Sätzen, was in diesem Repo ist.`
- [ ] Vom Handy aus eine Mail mit einem beliebigen Link an deine `…XAgt`-Adresse schicken.

## 7. Rückmeldung
Bitte dieses Formular ausfüllen: **[Formular-Link eintragen]**. Es fragt nach deinem GitHub-Username, deiner `…XAgt`-Adresse und ob der Test funktioniert hat.
